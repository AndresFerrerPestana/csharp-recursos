CSharp_PortesEncomenda

Valor de fronteira e cálculo condicional.

← Voltar ao índice

Objetivo

Calcular portes de 4,90 € para encomendas inferiores a 50 € e portes gratuitos a partir de 50 €.

decimal.TryParseif / elsedecimal€

Código

Versão moderna
Adequada a projetos com instruções de nível superior.
Descarregar .cs 
using System.Text;

Console.OutputEncoding = Encoding.UTF8;

Console.Write("Valor da encomenda: ");

if (decimal.TryParse(Console.ReadLine(), out decimal valor) && valor >= 0)
{
    decimal portes;

    if (valor >= 50m)
        portes = 0m;
    else
        portes = 4.90m;

    decimal total = valor + portes;

    Console.WriteLine($"Encomenda: {valor:F2} €");
    Console.WriteLine($"Portes: {portes:F2} €");
    Console.WriteLine($"Total: {total:F2} €");
}
else
{
    Console.WriteLine("Valor inválido.");
}
Versão compatível com compiladores online
Inclui explicitamente Program e Main().
Descarregar .cs 
using System;
using System.Text;

class Program
{
    static void Main()
    {
        Console.OutputEncoding = Encoding.UTF8;

        Console.Write("Valor da encomenda: ");

        if (decimal.TryParse(Console.ReadLine(), out decimal valor) && valor >= 0)
        {
            decimal portes;

            if (valor >= 50m)
                portes = 0m;
            else
                portes = 4.90m;

            decimal total = valor + portes;

            Console.WriteLine($"Encomenda: {valor:F2} €");
            Console.WriteLine($"Portes: {portes:F2} €");
            Console.WriteLine($"Total: {total:F2} €");
        }
        else
        {
            Console.WriteLine("Valor inválido.");
        }
    }
}
Entrada no OneCompiler: Uma linha com o valor da encomenda. Ex.: `49.99`.
Porque existem duas versões? O Visual Studio com C# moderno pode utilizar instruções de nível superior. Alguns compiladores online utilizam a estrutura tradicional com Program e Main().

Como funciona

  • O limite de 50 € pertence ao caso sem portes.
  • `decimal` é utilizado por se tratar de valores monetários.

Erros frequentes

  • Usar `>` em vez de `>=`.
  • Somar portes antes de definir o valor correto.
  • Aceitar valores negativos sem validação.
