CSharp_ValidarIntervalo

Exercício com do...while e validação repetida.

← Voltar ao índice

Objetivo

Pedir um inteiro entre 1 e 10 até receber uma entrada válida.

do...whileTryParseboolintervalo

Código

Versão moderna
Adequada a projetos com instruções de nível superior.
Descarregar .cs
int numero;
bool valido;

do
{
    Console.Write("Introduza um inteiro entre 1 e 10: ");

    valido = int.TryParse(Console.ReadLine(), out numero)
             && numero >= 1 && numero <= 10;

    if (!valido)
    {
        Console.WriteLine("Valor invalido. Tente novamente.");
    }

} while (!valido);

Console.WriteLine($"Valor aceite: {numero}");
Versão compatível com compiladores online
Inclui explicitamente Program e Main().
Descarregar .cs 
using System;

class Program
{
    static void Main()
    {
        int numero;
        bool valido;

        do
        {
            Console.Write("Introduza um inteiro entre 1 e 10: ");

            valido = int.TryParse(Console.ReadLine(), out numero)
                     && numero >= 1 && numero <= 10;

            if (!valido)
            {
                Console.WriteLine("Valor invalido. Tente novamente.");
            }

        } while (!valido);

        Console.WriteLine($"Valor aceite: {numero}");
    }
}
Entrada no OneCompiler: Introduzir tentativas, uma por linha, terminando com um valor válido. Ex.: `abc`, `0`, `11`, `5`.
Porque existem duas versões? O Visual Studio com C# moderno pode utilizar instruções de nível superior. Alguns compiladores online utilizam a estrutura tradicional com Program e Main().

Como funciona

  • O bloco executa pelo menos uma vez.
  • `valido` combina conversão e limites.
  • O ciclo repete enquanto `!valido` for verdadeiro.

Testes recomendados

Entrada / situaçãoResultado esperadoObjetivo

Erros frequentes

  • Usar `while (valido)` em vez de `while (!valido)`.
  • Esquecer de recalcular `valido` em cada iteração.
  • Não terminar o STDIN online com um valor válido.
