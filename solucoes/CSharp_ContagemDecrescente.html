CSharp_ContagemDecrescente

Exercício com for e decremento.

← Voltar ao índice

Objetivo

Ler um inteiro entre 0 e 20 e contar desse valor até 0, incluindo ambos os extremos.

forcontador--TryParsefronteiras

Código

Versão moderna
Adequada a projetos com instruções de nível superior.
Descarregar .cs
Console.Write("Introduza um inteiro entre 0 e 20: ");

if (int.TryParse(Console.ReadLine(), out int numero)
    && numero >= 0 && numero <= 20)
{
    for (int contador = numero; contador >= 0; contador--)
    {
        Console.WriteLine(contador);
    }

    Console.WriteLine("Contagem terminada.");
}
else
{
    Console.WriteLine("Valor invalido.");
}
Versão compatível com compiladores online
Inclui explicitamente Program e Main().
Descarregar .cs 
using System;

class Program
{
    static void Main()
    {
        Console.Write("Introduza um inteiro entre 0 e 20: ");

        if (int.TryParse(Console.ReadLine(), out int numero)
            && numero >= 0 && numero <= 20)
        {
            for (int contador = numero; contador >= 0; contador--)
            {
                Console.WriteLine(contador);
            }

            Console.WriteLine("Contagem terminada.");
        }
        else
        {
            Console.WriteLine("Valor invalido.");
        }
    }
}
Entrada no OneCompiler: Uma linha com um inteiro entre 0 e 20. Ex.: `3`.
Porque existem duas versões? O Visual Studio com C# moderno pode utilizar instruções de nível superior. Alguns compiladores online utilizam a estrutura tradicional com Program e Main().

Como funciona

  • O contador começa no valor introduzido.
  • `contador >= 0` inclui o zero.
  • `contador--` aproxima o contador do fim.

Erros frequentes

  • Usar `contador++` numa contagem decrescente.
  • Usar `contador > 0` e omitir zero.
  • Apresentar a mensagem final dentro do ciclo.
