Acrescentar a diferença sem alterar as outras opções.

← Voltar ao índice

Enunciado

Criar uma aplicação nova e copiar as duas partes do tutorial para Program.cs. Acrescentar a opção 3 — Diferença, com static int Subtrair(int primeiro, int segundo). Atualizar o menu, o limite máximo da leitura da opção e o switch. Manter as opções 0, 1 e 2 e o intervalo de -100 a 100 para os números.

static void MostrarMenu()
{
    Console.WriteLine("1 - Somar");
    Console.WriteLine("2 - Maior de dois valores");
    Console.WriteLine("3 - Diferença");
    Console.WriteLine("0 - Terminar");
}

static int LerInteiroNoIntervalo(string mensagem,
    int minimo, int maximo)
{
    int numero;
    bool valido;
    do
    {
        Console.Write(mensagem);
        // Validar a conversão antes de aceitar o valor.
        valido = int.TryParse(Console.ReadLine(), out numero)
            && numero >= minimo && numero <= maximo;
        if (!valido)
        {
            Console.WriteLine(
                $"Introduza um inteiro entre {minimo} e {maximo}.");
        }
    } while (!valido);
    return numero; // Só devolve um valor aceite.
}

static int Somar(int primeiro, int segundo)
{
    return primeiro + segundo;
}

static int Maior(int primeiro, int segundo)
{
    if (primeiro >= segundo)
    {
        return primeiro;
    }
    return segundo;
}

static int Subtrair(int primeiro, int segundo)
{
    return primeiro - segundo;
}

Entradas: Fornecer a opção, os dois números quando a opção não for 0 e as opções seguintes, uma entrada por linha. Terminar sempre com 0. Exemplo completo: 3, 7, 5, 0 (quatro linhas). Após uma entrada inválida, fornecer uma entrada válida para a mesma pergunta. Sem o 0 final, a execução continua à espera de opções.
Porque existem duas versões? O Visual Studio com C# moderno pode utilizar instruções de nível superior. Para C# (mono) no OnlineGDB, a versão online coloca as instruções em Program.Main() e as funções como métodos static da classe. Mantém os mesmos parâmetros, cálculos, mensagens e resultados; no Visual Studio, usar a versão do manual com funções locais static.

Como funciona

  • O menu, o limite da opção e o switch incluem agora a opção 3.
  • Subtrair devolve primeiro - segundo: a ordem dos argumentos importa.
  • As opções 0, 1 e 2 mantêm o comportamento do tutorial.

Resultado esperado

Nos exemplos com entrada, a transcrição inclui os valores escritos. Nas calculadoras, apresenta-se o resumo do percurso.

Entradas, uma por linha: 3, 7, 5, 0
Resultado do cálculo: Diferença: 2
O menu reaparece e termina com Programa terminado.

Erros frequentes

  • Copiar apenas parte do programa ou misturar as duas versões no mesmo ficheiro.
  • Confundir o valor devolvido por return com uma mensagem escrita na consola.
  • Alterar a ordem ou os tipos dos argumentos sem rever os parâmetros.
