Exercício integrado com do...while, switch, for e acumulador.

Objetivo

Construir um menu repetitivo com duas operações e uma opção de saída.

do...whileswitchforacumulador

Código

Versão moderna
Adequada a projetos com instruções de nível superior.
Descarregar .cs
int opcao;

do
{
    Console.WriteLine("1 - Somar os numeros de 1 a 5");
    Console.WriteLine("2 - Mostrar os pares de 2 a 10");
    Console.WriteLine("0 - Terminar");
    Console.Write("Opcao: ");

    if (!int.TryParse(Console.ReadLine(), out opcao))
    {
        opcao = -1;
    }

    switch (opcao)
    {
        case 1:
            int soma = 0;

            for (int numero = 1; numero <= 5; numero++)
            {
                soma += numero;
            }

            Console.WriteLine($"Soma: {soma}");
            break;

        case 2:
            for (int numero = 2; numero <= 10; numero++)
            {
                if (numero % 2 == 0)
                {
                    Console.WriteLine(numero);
                }
            }
            break;

        case 0:
            Console.WriteLine("Programa terminado.");
            break;

        default:
            Console.WriteLine("Opcao invalida.");
            break;
    }

} while (opcao != 0);
Versão compatível com compiladores online
Inclui explicitamente Program e Main().
Descarregar .cs 
using System;

class Program
{
    static void Main()
    {
        int opcao;

        do
        {
            Console.WriteLine("1 - Somar os numeros de 1 a 5");
            Console.WriteLine("2 - Mostrar os pares de 2 a 10");
            Console.WriteLine("0 - Terminar");
            Console.Write("Opcao: ");

            if (!int.TryParse(Console.ReadLine(), out opcao))
            {
                opcao = -1;
            }

            switch (opcao)
            {
                case 1:
                    int soma = 0;

                    for (int numero = 1; numero <= 5; numero++)
                    {
                        soma += numero;
                    }

                    Console.WriteLine($"Soma: {soma}");
                    break;

                case 2:
                    for (int numero = 2; numero <= 10; numero++)
                    {
                        if (numero % 2 == 0)
                        {
                            Console.WriteLine(numero);
                        }
                    }
                    break;

                case 0:
                    Console.WriteLine("Programa terminado.");
                    break;

                default:
                    Console.WriteLine("Opcao invalida.");
                    break;
            }

        } while (opcao != 0);
    }
}
Entrada no OneCompiler: Introduzir opções, uma por linha, terminando com `0`. Ex.: `1`, `2`, `0`.
Porque existem duas versões? O Visual Studio com C# moderno pode utilizar instruções de nível superior. Alguns compiladores online utilizam a estrutura tradicional com Program e Main().

Como funciona

  • O menu repete com `do...while`.
  • `switch` seleciona a operação.
  • A opção 1 usa um acumulador.
  • A opção 2 combina `for`, `%` e `if`.
  • O `break` de cada `case` não termina o ciclo exterior.

Testes recomendados

Entrada / situaçãoResultado esperadoObjetivo

Erros frequentes

  • Reinicializar o acumulador dentro do `for`.
  • Usar `break` esperando terminar o `do...while`.
  • Não distinguir uma conversão inválida da opção 0.
