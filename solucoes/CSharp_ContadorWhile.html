Condição inicial e variável de controlo.

← Voltar ao índice

Objetivo

Ler um limite entre 1 e 10 e apresentar os valores de 1 até esse limite utilizando while.

whilecontadorTryParselimites

Código

Versão moderna
Adequada a projetos com instruções de nível superior.
Descarregar .cs
Console.Write("Limite de 1 a 10: ");

if (int.TryParse(Console.ReadLine(), out int limite)
    && limite >= 1 && limite <= 10)
{
    int contador = 1;

    while (contador <= limite)
    {
        Console.WriteLine(contador);
        contador++;
    }
}
else
{
    Console.WriteLine("Introduza um inteiro de 1 a 10.");
}
Versão compatível com compiladores online
Inclui explicitamente Program e Main().
Descarregar .cs 
using System;

class Program
{
    static void Main()
    {
        Console.Write("Limite de 1 a 10: ");

        if (int.TryParse(Console.ReadLine(), out int limite)
            && limite >= 1 && limite <= 10)
        {
            int contador = 1;

            while (contador <= limite)
            {
                Console.WriteLine(contador);
                contador++;
            }
        }
        else
        {
            Console.WriteLine("Introduza um inteiro de 1 a 10.");
        }
    }
}
Entrada no OneCompiler: Uma linha com um valor entre 1 e 10. Ex.: `5`.
Porque existem duas versões? O Visual Studio com C# moderno pode utilizar instruções de nível superior. Alguns compiladores online utilizam a estrutura tradicional com Program e Main().

Como funciona

  • A condição é testada antes de cada iteração.
  • O contador começa em 1.
  • `contador++` aproxima a variável do fim do ciclo.

Testes recomendados

Entrada / situaçãoResultado esperadoObjetivo
11Uma iteração.
31, 2, 3Várias iterações.

0Mensagem de entrada inválidaFora do intervalo.
abcMensagem de entrada inválidaEntrada não numérica.

Erros frequentes

  • Esquecer `contador++`, provocando um ciclo infinito.
  • Usar `<` quando o limite deve ser incluído.
  • Inicializar o contador com um valor incorreto.
