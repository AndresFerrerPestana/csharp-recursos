Exercício com while e validação de intervalo.

← Voltar ao índice

Objetivo

Ler um inteiro entre 1 e 20 e apresentar os números de 1 até ao valor introduzido.

whileTryParsecontadorlimites

Código

Versão moderna
Adequada a projetos com instruções de nível superior.
Descarregar .cs
Console.Write("Introduza um inteiro entre 1 e 20: ");

if (int.TryParse(Console.ReadLine(), out int limite)
    && limite >= 1 && limite <= 20)
{
    int contador = 1;

    while (contador <= limite)
    {
        Console.WriteLine(contador);
        contador++;
    }
}
else
{
    Console.WriteLine("Valor invalido.");
}
Versão compatível com compiladores online
Inclui explicitamente Program e Main().
Descarregar .cs Abrir no OnlineGDB
Como testar no OnlineGDB: clicar em «Copiar versão online» e depois em «Abrir no OnlineGDB». Manter a linguagem C# (mono), selecionar todo o código inicial em main.cs e substituí-lo com Ctrl+V. O código não é transferido automaticamente. Clicar em Run. Em Interactive Console, escrever cada resposta e premir Enter; em Text, preencher previamente todas as entradas, uma por linha, antes de executar.
using System;

class Program
{
    static void Main()
    {
        Console.Write("Introduza um inteiro entre 1 e 20: ");

        if (int.TryParse(Console.ReadLine(), out int limite)
            && limite >= 1 && limite <= 20)
        {
            int contador = 1;

            while (contador <= limite)
            {
                Console.WriteLine(contador);
                contador++;
            }
        }
        else
        {
            Console.WriteLine("Valor invalido.");
        }
    }
}
Entrada no OnlineGDB: Uma linha com um inteiro entre 1 e 20. Ex.: `5`.
Porque existem duas versões? O Visual Studio com C# moderno pode utilizar instruções de nível superior. Alguns compiladores online utilizam a estrutura tradicional com Program e Main().

Como funciona

  • O ciclo só começa quando a entrada é válida.
  • `contador <= limite` inclui o limite.
  • O contador é atualizado em cada iteração.

Erros frequentes

  • Começar o contador em 0 quando o enunciado pede 1.
  • Usar `< limite` e omitir o último valor.
  • Esquecer a atualização.
