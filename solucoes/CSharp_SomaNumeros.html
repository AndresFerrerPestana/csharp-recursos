CSharp_SomaNumeros

Exercício com for e acumulador.

← Voltar ao índice

Objetivo

Calcular a soma dos inteiros de 1 até n, com n entre 1 e 100.

foracumuladorsoma +=TryParse

Código

Versão moderna
Adequada a projetos com instruções de nível superior.
Descarregar .cs
Console.Write("Introduza um inteiro entre 1 e 100: ");

if (int.TryParse(Console.ReadLine(), out int n)
    && n >= 1 && n <= 100)
{
    int soma = 0;

    for (int numero = 1; numero <= n; numero++)
    {
        soma += numero;
    }

    Console.WriteLine($"Soma: {soma}");
}
else
{
    Console.WriteLine("Valor invalido.");
}
Versão compatível com compiladores online
Inclui explicitamente Program e Main().
Descarregar .cs Abrir no OnlineGDB
Como testar no OnlineGDB: clicar em «Copiar versão online» e depois em «Abrir no OnlineGDB». Manter a linguagem C# (mono), selecionar todo o código inicial em main.cs e substituí-lo com Ctrl+V. O código não é transferido automaticamente. Clicar em Run. Em Interactive Console, escrever cada resposta e premir Enter; em Text, preencher previamente todas as entradas, uma por linha, antes de executar.
using System;

class Program
{
    static void Main()
    {
        Console.Write("Introduza um inteiro entre 1 e 100: ");

        if (int.TryParse(Console.ReadLine(), out int n)
            && n >= 1 && n <= 100)
        {
            int soma = 0;

            for (int numero = 1; numero <= n; numero++)
            {
                soma += numero;
            }

            Console.WriteLine($"Soma: {soma}");
        }
        else
        {
            Console.WriteLine("Valor invalido.");
        }
    }
}
Entrada no OnlineGDB: Uma linha com um inteiro entre 1 e 100. Ex.: `3`.
Porque existem duas versões? O Visual Studio com C# moderno pode utilizar instruções de nível superior. Alguns compiladores online utilizam a estrutura tradicional com Program e Main().

Como funciona

  • `soma` é inicializada uma única vez antes do ciclo.
  • Cada iteração acrescenta o valor atual do contador.
  • O resultado final só é apresentado depois do ciclo.

Erros frequentes

  • Reinicializar `soma = 0` dentro do ciclo.
  • Começar a contagem em 0 sem necessidade.
  • Apresentar apenas o último número em vez do acumulado.
