Combinação de condições com && e ||.

← Voltar ao índice

Objetivo

Permitir acesso apenas quando a idade é pelo menos 18 e existe autorização S/s.

int.TryParsebool&&||

Código

Versão moderna
Adequada a projetos com instruções de nível superior.
Descarregar .cs

if (!int.TryParse(Console.ReadLine(), out int idade))

    Console.WriteLine("Idade inválida.");

using System;

class Program
{
    static void Main()
    {
        Console.Write("Idade: ");

        if (!int.TryParse(Console.ReadLine(), out int idade))
        {
            Console.WriteLine("Idade inválida.");
        }
        else
        {
            Console.Write("Existe autorização? (S/N): ");
            string resposta = (Console.ReadLine() ?? "").Trim();

            bool autorizacao = resposta == "S" || resposta == "s";

            if (idade >= 18 && autorizacao)
            {
                Console.WriteLine("Acesso permitido.");
            }
            else
            {
                Console.WriteLine("Acesso não permitido.");
            }
        }
    }
}
Entrada no OnlineGDB: Duas linhas: idade e autorização. Ex.: `20` e `S`.
Porque existem duas versões? O Visual Studio com C# moderno pode utilizar instruções de nível superior. Alguns compiladores online utilizam a estrutura tradicional com Program e Main().

Como funciona

  • A autorização é transformada numa expressão `bool`.
  • `||` aceita S ou s.
  • `&&` exige simultaneamente idade suficiente e autorização.

Erros frequentes

  • Usar `||` entre idade e autorização.
  • Duplicar toda a lógica para S e s.
  • Não tratar idade inválida.
