Objetivo

Criar o menu 1 — somar, 2 — maior de dois valores e 0 — terminar. Aceitar inteiros entre -100 e 100 e repetir qualquer leitura inválida.

static void MostrarMenu()
{
    Console.WriteLine("1 - Somar");
    Console.WriteLine("2 - Maior de dois valores");
    Console.WriteLine("0 - Terminar");
}

static int LerInteiroNoIntervalo(string mensagem,
    int minimo, int maximo)
{
    int numero;
    bool valido;
    do
    {
        Console.Write(mensagem);
        // Validar a conversão antes de aceitar o valor.
        valido = int.TryParse(Console.ReadLine(), out numero)
            && numero >= minimo && numero <= maximo;
        if (!valido)
        {
            Console.WriteLine(
                $"Introduza um inteiro entre {minimo} e {maximo}.");
        }
    } while (!valido);
    return numero; // Só devolve um valor aceite.
}

static int Somar(int primeiro, int segundo)
{
    return primeiro + segundo;
}

static int Maior(int primeiro, int segundo)
{
    if (primeiro >= segundo)
    {
        return primeiro;
    }
    return segundo;
}

Descarregar .cs Abrir no OnlineGDB
Como testar no OnlineGDB: clicar em «Copiar versão online» e depois em «Abrir no OnlineGDB». Manter a linguagem C# (mono), selecionar todo o código inicial em main.cs e substituí-lo com Ctrl+V. O código não é transferido automaticamente. Clicar em Run. Em Interactive Console, escrever cada resposta e premir Enter; em Text, preencher previamente todas as entradas, uma por linha, antes de executar.
using System;

class Program
{
    static void Main()
    {
        int opcao;
        do
        {
            MostrarMenu();
            opcao = LerInteiroNoIntervalo("Opção: ", 0, 2);
            if (opcao != 0)
            {
                int primeiro = LerInteiroNoIntervalo(
                    "Primeiro número [-100, 100]: ", -100, 100);
                int segundo = LerInteiroNoIntervalo(
                    "Segundo número [-100, 100]: ", -100, 100);
                switch (opcao)
                {
                    case 1:
                        int soma = Somar(primeiro, segundo);
                        Console.WriteLine($"Soma: {soma}");
                        break;
                    case 2:
                        int maior = Maior(primeiro, segundo);
                        Console.WriteLine($"Maior: {maior}");
                        break;
                }
            }
        } while (opcao != 0);
        Console.WriteLine("Programa terminado.");
    }

    static void MostrarMenu()
    {
        Console.WriteLine("1 - Somar");
        Console.WriteLine("2 - Maior de dois valores");
        Console.WriteLine("0 - Terminar");
    }

    static int LerInteiroNoIntervalo(string mensagem,
        int minimo, int maximo)
    {
        int numero;
        bool valido;
        do
        {
            Console.Write(mensagem);
            // Validar a conversão antes de aceitar o valor.
            valido = int.TryParse(Console.ReadLine(), out numero)
                && numero >= minimo && numero <= maximo;
            if (!valido)
            {
                Console.WriteLine(
                    $"Introduza um inteiro entre {minimo} e {maximo}.");
            }
        } while (!valido);
        return numero; // Só devolve um valor aceite.
    }

    static int Somar(int primeiro, int segundo)
    {
        return primeiro + segundo;
    }

    static int Maior(int primeiro, int segundo)
    {
        if (primeiro >= segundo)
        {
            return primeiro;
        }
        return segundo;
    }
}
Entradas: Fornecer a opção, os dois números quando a opção não for 0 e as opções seguintes, uma entrada por linha. Terminar sempre com 0. Exemplo completo: 1, 7, 5, 0 (quatro linhas). Após uma entrada inválida, fornecer uma entrada válida para a mesma pergunta. Sem o 0 final, a execução continua à espera de opções.
Porque existem duas versões? O Visual Studio com C# moderno pode utilizar instruções de nível superior. Para C# (mono) no OnlineGDB, a versão online coloca as instruções em Program.Main() e as funções como métodos static da classe. Mantém os mesmos parâmetros, cálculos, mensagens e resultados; no Visual Studio, usar a versão do manual com funções locais static.

Como funciona

  • As duas partes do manual estão reunidas num único programa completo.
  • LerInteiroNoIntervalo só devolve um valor aceite.
  • Somar e Maior não dependem da consola.
  • A opção 0 termina sem pedir operandos.

Resultado esperado

Nos exemplos com entrada, a transcrição inclui os valores escritos. Nas calculadoras, apresenta-se o resumo do percurso.

Entradas, uma por linha: 1, 7, 5, 0
Resultado do cálculo: Soma: 12
O menu reaparece e termina com Programa terminado.

Erros frequentes

  • Copiar apenas parte do programa ou misturar as duas versões no mesmo ficheiro.
  • Confundir o valor devolvido por return com uma mensagem escrita na consola.
  • Alterar a ordem ou os tipos dos argumentos sem rever os parâmetros.
