Objetivo

Calcular subtotal, IVA e total a partir de um preço unitário e de uma quantidade.

decimalaritméticaF2UTF-8

Código

Versão moderna
Adequada a projetos com instruções de nível superior.
Descarregar .cs 
using System.Text;

Console.OutputEncoding = Encoding.UTF8;

decimal precoUnitario = 18.50m;
int quantidade = 3;

decimal subtotal = precoUnitario * quantidade;
decimal iva = subtotal * 0.23m;
decimal total = subtotal + iva;

Console.WriteLine($"Subtotal: {subtotal:F2} €");
Console.WriteLine($"IVA: {iva:F2} €");
Console.WriteLine($"Total: {total:F2} €");

using System;
using System.Text;

class Program
{
    static void Main()
    {
        Console.OutputEncoding = Encoding.UTF8;

        decimal precoUnitario = 18.50m;
        int quantidade = 3;

        decimal subtotal = precoUnitario * quantidade;
        decimal iva = subtotal * 0.23m;
        decimal total = subtotal + iva;

        Console.WriteLine($"Subtotal: {subtotal:F2} €");
        Console.WriteLine($"IVA: {iva:F2} €");
        Console.WriteLine($"Total: {total:F2} €");
    }
}
Entrada no OnlineGDB: Não utiliza entrada interativa.
Porque existem duas versões? O Visual Studio com C# moderno pode utilizar instruções de nível superior. Alguns compiladores online utilizam a estrutura tradicional com Program e Main().

Como funciona

  • `decimal` é adequado a valores monetários.
  • `0.23m` representa 23% em `decimal`.
  • `F2` apresenta duas casas decimais.
  • `Encoding.UTF8` melhora a apresentação do símbolo `€` em consolas compatíveis.

Erros frequentes

  • Usar `double` sem necessidade para valores monetários.
  • Esquecer o sufixo `m` em literais `decimal`.
  • Calcular o IVA sobre o total em vez do subtotal.
