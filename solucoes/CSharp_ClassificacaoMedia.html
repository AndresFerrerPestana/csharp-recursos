Média aritmética e cadeia else if.

← Voltar ao índice

Objetivo

Ler três valores, calcular a média e apresentar uma classificação de acordo com intervalos definidos.

double.TryParsemédiaelse ifF2

Código

Versão moderna
Adequada a projetos com instruções de nível superior.
Descarregar .cs 
Console.Write("Primeiro valor: ");
bool v1Valido = double.TryParse(Console.ReadLine(), out double valor1);

Console.Write("Segundo valor: ");
bool v2Valido = double.TryParse(Console.ReadLine(), out double valor2);

Console.Write("Terceiro valor: ");
bool v3Valido = double.TryParse(Console.ReadLine(), out double valor3);

if (!v1Valido || !v2Valido || !v3Valido)
{
    Console.WriteLine("Valor inválido.");
}
else
{
    double media = (valor1 + valor2 + valor3) / 3;

    Console.WriteLine($"Média: {media:F2}");

    if (media >= 18)
        Console.WriteLine("Muito bom");
    else if (media >= 14)
        Console.WriteLine("Bom");
    else if (media >= 10)
        Console.WriteLine("Suficiente");
    else
        Console.WriteLine("Insuficiente");
}
Versão compatível com compiladores online
Inclui explicitamente Program e Main().
Descarregar .cs 
using System;

class Program
{
    static void Main()
    {
        Console.Write("Primeiro valor: ");
        bool v1Valido = double.TryParse(Console.ReadLine(), out double valor1);

        Console.Write("Segundo valor: ");
        bool v2Valido = double.TryParse(Console.ReadLine(), out double valor2);

        Console.Write("Terceiro valor: ");
        bool v3Valido = double.TryParse(Console.ReadLine(), out double valor3);

        if (!v1Valido || !v2Valido || !v3Valido)
        {
            Console.WriteLine("Valor inválido.");
        }
        else
        {
            double media = (valor1 + valor2 + valor3) / 3;

            Console.WriteLine($"Média: {media:F2}");

            if (media >= 18)
                Console.WriteLine("Muito bom");
            else if (media >= 14)
                Console.WriteLine("Bom");
            else if (media >= 10)
                Console.WriteLine("Suficiente");
            else
                Console.WriteLine("Insuficiente");
        }
    }
}
Entrada no OneCompiler: Três linhas com os valores. Ex.: `18`, `17`, `19`.
Porque existem duas versões? O Visual Studio com C# moderno pode utilizar instruções de nível superior. Alguns compiladores online utilizam a estrutura tradicional com Program e Main().

Como funciona

  • A média é calculada apenas quando as três entradas são válidas.
  • As condições devem ser avaliadas do valor mais alto para o mais baixo.

Erros frequentes

  • Colocar `media >= 10` antes de `media >= 18`.
  • Dividir apenas o último valor por 3 por falta de parênteses.
  • Não validar as três entradas.
