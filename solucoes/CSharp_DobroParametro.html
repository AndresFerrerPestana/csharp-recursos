CSharp_DobroParametro

Passar argumentos a uma função com um parâmetro.

← Voltar ao índice

Objetivo

Chamar MostrarDobro com 4, 0 e -3. A função recebe o inteiro, calcula o dobro e apresenta a mensagem.

parâmetroargumentovoid

Código

Versão moderna
Adequada a projetos com instruções de nível superior.
Descarregar .cs
MostrarDobro(4);
MostrarDobro(0);
int valor = -3;
MostrarDobro(valor);

static void MostrarDobro(int numero)
{
    int dobro = numero * 2;
    Console.WriteLine($"Dobro de {numero}: {dobro}");
}
Versão compatível com compiladores online
Inclui explicitamente Program e Main().
Descarregar .cs Abrir no OnlineGDB
Como testar no OnlineGDB: clicar em «Copiar versão online» e depois em «Abrir no OnlineGDB». Manter a linguagem C# (mono), selecionar todo o código inicial em main.cs e substituí-lo com Ctrl+V. O código não é transferido automaticamente. Clicar em Run. Em Interactive Console, escrever cada resposta e premir Enter; em Text, preencher previamente todas as entradas, uma por linha, antes de executar.
using System;

class Program
{
    static void Main()
    {
        MostrarDobro(4);
        MostrarDobro(0);
        int valor = -3;
        MostrarDobro(valor);
    }

    static void MostrarDobro(int numero)
    {
        int dobro = numero * 2;
        Console.WriteLine($"Dobro de {numero}: {dobro}");
    }
}
Entradas: Este programa não lê dados. Executar diretamente; nos testes de alteração, modificar os valores no código e executar novamente.
Porque existem duas versões? O Visual Studio com C# moderno pode utilizar instruções de nível superior. Para C# (mono) no OnlineGDB, a versão online coloca as instruções em Program.Main() e as funções como métodos static da classe. Mantém os mesmos parâmetros, cálculos, mensagens e resultados; no Visual Studio, usar a versão do manual com funções locais static.

Como funciona

  • numero é o parâmetro; 4, 0 e valor são argumentos.
  • Cada chamada recebe uma nova cópia do argumento.
  • O exemplo não lê dados: para outros testes, alterar os argumentos.

Resultado esperado

Nos exemplos com entrada, a transcrição inclui os valores escritos. Nas calculadoras, apresenta-se o resumo do percurso.

Dobro de 4: 8
Dobro de 0: 0
Dobro de -3: -6

Testes recomendados

A barra / separa linhas de entrada; o ponto e vírgula separa execuções independentes. «Linha vazia» significa premir Enter sem escrever.

Erros frequentes

  • Copiar apenas parte do programa ou misturar as duas versões no mesmo ficheiro.
  • Confundir o valor devolvido por return com uma mensagem escrita na consola.
  • Alterar a ordem ou os tipos dos argumentos sem rever os parâmetros.
