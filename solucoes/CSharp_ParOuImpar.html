CSharp_ParOuImpar

Validação com TryParse, operador % e if/else.

← Voltar ao índice

Objetivo

Ler um número inteiro, validar a entrada e indicar se o número é par ou ímpar.

int.TryParse%if / else

Código

Versão moderna
Adequada a projetos com instruções de nível superior.
Descarregar .cs 
Console.Write("Introduza um número inteiro: ");

if (int.TryParse(Console.ReadLine(), out int numero))
{
    if (numero % 2 == 0)
    {
        Console.WriteLine("O número é par.");
    }
    else
    {
        Console.WriteLine("O número é ímpar.");
    }
}
else
{
    Console.WriteLine("Valor inválido. Introduza um número inteiro.");
}
Versão compatível com compiladores online
Inclui explicitamente Program e Main().
Descarregar .cs 
using System;

class Program
{
    static void Main()
    {
        Console.Write("Introduza um número inteiro: ");

        if (int.TryParse(Console.ReadLine(), out int numero))
        {
            if (numero % 2 == 0)
            {
                Console.WriteLine("O número é par.");
            }
            else
            {
                Console.WriteLine("O número é ímpar.");
            }
        }
        else
        {
            Console.WriteLine("Valor inválido. Introduza um número inteiro.");
        }
    }
}
Entrada no OneCompiler: Uma linha com o número a testar. Ex.: `8`.
Porque existem duas versões? O Visual Studio com C# moderno pode utilizar instruções de nível superior. Alguns compiladores online utilizam a estrutura tradicional com Program e Main().

Como funciona

  • `int.TryParse` valida a entrada.
  • `numero % 2` calcula o resto da divisão por 2.
  • Resto 0 significa número par.

Erros frequentes

  • Usar `/` em vez de `%`.
  • Usar `=` em vez de `==`.
  • Não testar zero ou valores negativos.
