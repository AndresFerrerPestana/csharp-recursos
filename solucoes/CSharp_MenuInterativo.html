CSharp_MenuInterativo

Integração de do...while, switch, for e validação.

← Voltar ao índice

Objetivo

Criar um menu que permita mostrar uma mensagem, apresentar uma contagem de 1 a 5 e terminar.

do...whileswitchforTryParse

Código

Versão moderna
Adequada a projetos com instruções de nível superior.
Descarregar .cs
int opcao;

do
{
    Console.WriteLine("1 - Mostrar mensagem");
    Console.WriteLine("2 - Contar de 1 a 5");
    Console.WriteLine("0 - Terminar");
    Console.Write("Opcao: ");

    bool leituraValida = int.TryParse(Console.ReadLine(), out opcao);

    if (!leituraValida)
    {
        opcao = -1;
    }

    switch (opcao)
    {
        case 1:
            Console.WriteLine("O menu esta a funcionar.");
            break;

        case 2:
            for (int contador = 1; contador <= 5; contador++)
            {
                Console.WriteLine(contador);
            }
            break;

        case 0:
            Console.WriteLine("Programa terminado.");
            break;

        default:
            Console.WriteLine("Opcao invalida. Escolha 0, 1 ou 2.");
            break;
    }

} while (opcao != 0);
Versão compatível com compiladores online
Inclui explicitamente Program e Main().
Descarregar .cs 
using System;

class Program
{
    static void Main()
    {
        int opcao;

        do
        {
            Console.WriteLine("1 - Mostrar mensagem");
            Console.WriteLine("2 - Contar de 1 a 5");
            Console.WriteLine("0 - Terminar");
            Console.Write("Opcao: ");

            bool leituraValida = int.TryParse(Console.ReadLine(), out opcao);

            if (!leituraValida)
            {
                opcao = -1;
            }

            switch (opcao)
            {
                case 1:
                    Console.WriteLine("O menu esta a funcionar.");
                    break;

                case 2:
                    for (int contador = 1; contador <= 5; contador++)
                    {
                        Console.WriteLine(contador);
                    }
                    break;

                case 0:
                    Console.WriteLine("Programa terminado.");
                    break;

                default:
                    Console.WriteLine("Opcao invalida. Escolha 0, 1 ou 2.");
                    break;
            }

        } while (opcao != 0);
    }
}
Entrada no OneCompiler: Introduzir opções, uma por linha, terminando sempre com `0`. Ex.: `1`, `2`, `0`.
Porque existem duas versões? O Visual Studio com C# moderno pode utilizar instruções de nível superior. Alguns compiladores online utilizam a estrutura tradicional com Program e Main().

Como funciona

  • `do...while` mantém o menu disponível.
  • `TryParse` separa entrada válida de entrada não numérica.
  • `switch` escolhe a operação.
  • O `for` da opção 2 executa cinco iterações.
  • O `break` termina apenas o `switch`, não o ciclo exterior.

Testes recomendados

Erros frequentes

  • Esperar que o `break` de um `case` termine o `do...while`.
  • Não terminar a sequência de STDIN com 0 num compilador online.
  • Não distinguir uma leitura inválida da opção 0.
