CSharp_MenuDoWhile

Repetição com teste da condição no final.

← Voltar ao índice

Objetivo

Apresentar um menu pelo menos uma vez e repeti-lo até ser escolhida a opção 0.

do...whilemenuTryParsevalidação

Código

Versão moderna
Adequada a projetos com instruções de nível superior.
Descarregar .cs
int opcao;

do
{
    Console.WriteLine("1 - Mostrar mensagem");
    Console.WriteLine("0 - Terminar");
    Console.Write("Opcao: ");

    if (!int.TryParse(Console.ReadLine(), out opcao))
    {
        opcao = -1;
    }

    if (opcao == 1)
    {
        Console.WriteLine("Bem-vindo ao menu!");
    }
    else if (opcao != 0)
    {
        Console.WriteLine("Opcao invalida.");
    }

} while (opcao != 0);

Console.WriteLine("Programa terminado.");
Versão compatível com compiladores online
Inclui explicitamente Program e Main().
Descarregar .cs Abrir no OnlineGDB
Como testar no OnlineGDB: clicar em «Copiar versão online» e depois em «Abrir no OnlineGDB». Manter a linguagem C# (mono), selecionar todo o código inicial em main.cs e substituí-lo com Ctrl+V. O código não é transferido automaticamente. Clicar em Run. Em Interactive Console, escrever cada resposta e premir Enter; em Text, preencher previamente todas as entradas, uma por linha, antes de executar.
using System;

class Program
{
    static void Main()
    {
        int opcao;

        do
        {
            Console.WriteLine("1 - Mostrar mensagem");
            Console.WriteLine("0 - Terminar");
            Console.Write("Opcao: ");

            if (!int.TryParse(Console.ReadLine(), out opcao))
            {
                opcao = -1;
            }

            if (opcao == 1)
            {
                Console.WriteLine("Bem-vindo ao menu!");
            }
            else if (opcao != 0)
            {
                Console.WriteLine("Opcao invalida.");
            }

        } while (opcao != 0);

        Console.WriteLine("Programa terminado.");
    }
}
Entrada no OnlineGDB: Introduzir opções, uma por linha, terminando com `0`. Ex.: `1`, `1`, `0`.
Porque existem duas versões? O Visual Studio com C# moderno pode utilizar instruções de nível superior. Alguns compiladores online utilizam a estrutura tradicional com Program e Main().

Como funciona

  • O bloco é executado antes do primeiro teste.
  • A variável `opcao` é declarada antes do `do`.
  • Uma leitura inválida é representada por `-1`, evitando confusão com a opção de saída 0.

Testes recomendados

Entrada / situaçãoResultado esperadoObjetivo
0Programa terminado.Saída imediata.
1 / 0Mensagem e depois saída.Repetição válida.
2 / 0Opcao invalida e depois saída.Opção inexistente.
abc / 0Opcao invalida e depois saída.Entrada não numérica.

Erros frequentes

  • Declarar `opcao` apenas dentro do bloco e tentar usá-la na condição final.
  • Esquecer o ponto e vírgula em `while (opcao != 0);`.
  • Usar 0 para representar uma leitura inválida e terminar o menu por engano.
