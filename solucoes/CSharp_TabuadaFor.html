CSharp_TabuadaFor

Contagem definida com inicialização, condição e atualização.

← Voltar ao índice

Objetivo

Apresentar a tabuada do 7, de 1 a 10, utilizando um ciclo for.

forcontadortabuadainterpolação

Código

Versão moderna
Adequada a projetos com instruções de nível superior.
Descarregar .cs
int numero = 7;

for (int multiplicador = 1; multiplicador <= 10; multiplicador++)
{
    int resultado = numero * multiplicador;
    Console.WriteLine($"{numero} x {multiplicador} = {resultado}");
}
Versão compatível com compiladores online
Inclui explicitamente Program e Main().
Descarregar .cs 
using System;

class Program
{
    static void Main()
    {
        int numero = 7;

        for (int multiplicador = 1; multiplicador <= 10; multiplicador++)
        {
            int resultado = numero * multiplicador;
            Console.WriteLine($"{numero} x {multiplicador} = {resultado}");
        }
    }
}
Entrada no OneCompiler: Não utiliza entrada interativa.
Porque existem duas versões? O Visual Studio com C# moderno pode utilizar instruções de nível superior. Alguns compiladores online utilizam a estrutura tradicional com Program e Main().

Como funciona

  • A inicialização ocorre uma vez.
  • A condição é verificada antes de cada iteração.
  • A atualização ocorre depois do bloco.
  • O número permanece fixo e o multiplicador varia.

Testes recomendados

Entrada / situaçãoResultado esperadoObjetivo
numero = 77 x 1 = 7 ... 7 x 10 = 70Caso base.
numero = 0Dez resultados iguais a 0Confirma que o ciclo mantém 10 iterações.
numero = -2-2 x 1 ... -2 x 10Confirma funcionamento com negativo.

Erros frequentes

  • Usar `< 10` e produzir apenas nove linhas.
  • Alterar `numero` em vez de `multiplicador`.
  • Colocar um ponto e vírgula logo após o cabeçalho do `for`.
